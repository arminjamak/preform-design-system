# PreForm Design System

A token-first component library distilled from the **PreForm 3D Printing Interface** prototype
([arminjamak/PreForm-3D-Printing-Interface](https://github.com/arminjamak/PreForm-3D-Printing-Interface)).

## How it is layered

| Tier | Source | Example |
| --- | --- | --- |
| **Primitives** | `tokens/src/primitives.json` | `color.blue.600 = #0a63c9`, `space.3 = 12px`, `shadow.md` |
| **Semantic** | `tokens/src/semantic.light.json`, `semantic.dark.json` | `color.bg.accent → {color.blue.600}` |
| **Component** | `tokens/src/component.json` | `component.button.height-sm → {size.control.sm}` |
| **Components** | `src/components/*` | CSS Modules that only use `var(--…)` |

Tokens are authored in the W3C **Design Tokens Community Group** JSON format and compiled with
Style Dictionary 4 into `src/tokens/tokens.css` (light, `:root`), `tokens.dark.css` (`[data-theme="dark"]`),
`tokens.ts` (typed `var()` references) and `tokens.meta.json` (what the Foundations pages render).

## Rules

- **4pt grid.** Every spacing and size token is a multiple of 4px, except `space.px` (1) and `space.half` (2) for hairlines and insets.
- **No raw values in components.** `npm run lint:tokens` fails the build if a component stylesheet contains a hex colour or a px/rem/ms length outside `var()`.
- **Semantic over primitive.** Components reference `color.bg.*`, `color.fg.*`, `color.border.*`, never `color.blue.*`, so dark mode is a token swap.
- **Forced states.** Every interactive component accepts `data-state="hover" | "focus" | "active"`, which the *States* stories use to render every state without a pointer.

## Using the sandbox

- Pick a component in the sidebar. **Playground** exposes every prop in the Controls panel; the **Code** panel below the canvas shows the JSX for the current args.
- The **Theme** and **Surface** toolbar items switch dark mode and the background token behind the story.
- **Foundations** pages render straight from the compiled token metadata, so they can never drift from the CSS.

## Installing in an app

```tsx
import '@preform/design-system/src/styles/base.css';
import { Button, PanelShell, tokens } from '@preform/design-system';

<Button variant="primary">Generate Supports</Button>
// tokens.color.bg.accent === 'var(--color-bg-accent)'
```
